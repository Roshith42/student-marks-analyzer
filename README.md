# student-marks-analyzer
A simple Python project that analyzes student marks and calculates basic academic results.

Features
Accepts student marks as input
Calculates total and average marks
Determines pass/fail status
Displays the student’s performance
Technologies
Python
How to Run
python student_analyzer.py
Purpose

This project was created to practice Python programming concepts such as variables, input/output, conditional statements, loops, and basic calculations.
